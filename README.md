
# React-Job

React-Job is a web application that allows users to search for jobs and manage job listings seamlessly. Built with React, it provides a simple and intuitive interface for job seekers. The application uses static JSON data hosted on Vercel to simulate job listings.

## Features

- Search for jobs by title, company, or location.
- Save and manage job listings locally (e.g., browser state or local storage).
- Mobile-friendly responsive design.
- No authentication required — jump right into job searching!
- Static JSON data hosted on Vercel — no backend or RESTful API required.

## Installation

Follow these steps to set up the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Gogo602/React-Job.git
   ```
2. Navigate to the project directory:
   ```bash
   cd React-Job
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Open your browser and go to `http://localhost:3000`.

## Usage

- Open the application in your browser.
- Use the search bar to find jobs by title, company, or location.
- Save and manage job listings as needed.
- The app is designed for simplicity — no login or signup required.
- Job data is fetched from static JSON files hosted on Vercel.
